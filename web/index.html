The contract panel lives inside ODD

Contracts, their rules, the rows a failing check counted and the replication rules are on ODD Platform's own Data Quality page — next to the dashboard that says a check failed, rather than on a second port. This page used to be a second copy of that, and two of anything is two to maintain.

Open Data Quality in ODD →

This port is the API the panel talks to. The routes worth knowing:

  • GET /api/overview — scores, the trend, open failures
  • GET /api/contracts/{id} — one contract, its rules and checks
  • GET /api/checks/{id}/sample — the rows a check failed on
  • GET /api/rules/catalogue — the rules a form can offer
  • POST /api/rules/structured — add a rule without writing SQL
  • GET /api/sync — the replication rules, and whether they run

The full list is at /docs.
